Doctrine

  • No pruning. Every byte of the weight file lands in exactly one packet — even unclaimed bytes become __gap__/__file_tail__ nodes.
  • No quantization. Payload bytes are the patient's own bytes; zstd is bit-exact on decode. Roundtrip proven: 1c9c77a4…3ea4e.
  • No "impossible". Same information, new shape — chosen so HTTP, CDNs, browsers and WebGPU can all chew it.
  • Honest ledger. LFM3 raw 3.46 GB → 1,791 packets ≈ 2.70 GB over the wire (−22.0%); LFM2.5 raw 709 MB → 423 packets ≈ 551 MB (−22.3%). Verified bit-exact on assembly.

How the web architecture works

  1. Pack (CI, GitHub PAT): stream the safetensors → 2 MB packets (zstd, per-packet sha256) + graph manifest. Batched pushes to the weights branch.
  2. Manifest = the map: graph/*.json lists every tensor and its packets with checksums.
  3. Browser pages it in: the runtime walks the manifest, fetches packets with bounded concurrency from mirrors (raw.githubusercontent + jsDelivr), verifies each sha256, widens bf16→f32 losslessly.
  4. Run: OLAI-JS engine executes the exact LFM2.5 forward — output greedy-identical to PyTorch (verified in CI).
